## 🎯 Objective

This project aims to make studying and learning **JavaFX** significantly less complicated and much more enjoyable for modern developers. 

Historically, the official JavaFX documentation (like the FXML Tutorial and the CSS Reference Guide) consisted of massive, monolithic HTML files that were hard to read and navigate. This project completely revitalizes that experience by slicing the massive official documentation into almost 200 granular, easy-to-digest pages wrapped in a stunning, modern web interface.

## ✨ Features

- **Modern Web Architecture:** Built entirely from scratch using **Vue.js 3** and **Vite**.
- **Dark Mode & Glassmorphism:** A beautiful, eye-friendly aesthetic with glass panels, neon accents, and smooth animations.
- **HTML/Web Analogies:** For every FXML concept, there are custom-crafted analogies comparing JavaFX behaviors to standard Web/HTML equivalents (like React, Vue, or DOM APIs), bridging the gap for web developers learning desktop UI.
- **Component-Level CSS Reference:** The massive Oracle CSS Guide was automatically parsed and fragmented. Each JavaFX Control (like `Button`, `TableView`, `ComboBox`) now has its very own dedicated page containing all of its Substructures and Pseudo-classes.
- **Beautiful Tables & Code Blocks:** All legacy tables were converted to use **Bootstrap 5** dark-mode striped tables, and all raw code was formatted into syntax-highlighted blocks.
- **Collapsible Navigation:** A smart, accordion-style sidebar to easily navigate through hundreds of topics without visual clutter.

## 🛠️ Tech Stack

- [Vue.js 3](https://vuejs.org/) (Composition API)
- [Vue Router 4](https://router.vuejs.org/)
- [Vite](https://vitejs.dev/)
- [Bootstrap 5](https://getbootstrap.com/) (For tabular data styling)
- Custom CSS (Glassmorphism, Flexbox layouts)
- Python (Used for DOM extraction, regex parsing, and automating the component generation)

## 🚀 Getting Started

To run this documentation locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd vue-docs
   ```

2. **Install the dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the address shown in the terminal (usually `http://localhost:5173`).
