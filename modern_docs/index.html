Introduction to FXML

Release: JavaFX 26

Overview

FXML is a scriptable, XML-based markup language for constructing Java object graphs. It provides a convenient alternative to constructing such graphs in procedural code, and is ideally suited to defining the user interface of a JavaFX application.

The hierarchical structure of an XML document closely parallels the structure of the JavaFX scene graph, making it intuitive to design rich user interfaces.

Tip: FXML separates the user interface design from the application logic, making your code cleaner and easier to maintain.

Elements

In FXML, an XML element represents one of the following:

  • 🔹 A class instance
  • 🔹 A property of a class instance
  • 🔹 A "static" property
  • 🔹 A "define" block
  • 🔹 A block of script code

Class Instance Elements

Class instances can be constructed in FXML in several ways. The most common is via instance declaration elements, which simply create a new instance of a class by name.

Example: Instance Declaration
<VBox xmlns:fx="http://javafx.com/fxml">
    <Label text="Hello, Modern JavaFX!" />
</VBox>

Other ways of creating class instances include referencing existing values, copying existing values, and more.
